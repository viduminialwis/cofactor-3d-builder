Tips for docking cofactors (please read once)
  • Stereochemistry matters. Sugars in FAD/NAD(P)H must be D-ribose/D-ribityl. A SMILES without @/@@ gives a random isomer. The tool stops and warns you when this happens.
  • Oxidised vs reduced. Check the formula: FAD is C27H33N9O15P2; FADH2 has 2 more H. For FADH2 the correct form is the 1,5-dihydro flavin (H on N1 and N5).
  • Use SDF for PyRx. SDF keeps bond orders; PDB does not. Import the SDF into PyRx (Open Babel), minimise, then "Convert to AutoDock Ligand (pdbqt)".
  • Metal cofactors (heme, Fe–S, the AlkB di-iron centre) cannot be built this way. Take them from a crystal structure in the PDB.
  • Charges: PubChem SMILES are usually neutral (phosphates as –OH). Vina scoring does not use partial charges, but state the protonation state you used in your Methods.
  • Every run is recorded in generation_log.csv in the output folder (SMILES, seed, force field, energy), so you can write the Methods later.
